Description of the Program and how the program works
-

This program is a Security Incident Manager that uses Dictionaries to store information about a cyber security incident. The Dictionary contains the username (a.ashraf) , Ip address , event type and risk level of the incident. The program shows how dictionary data can be displayed , updated and added/ removed to system whilst manging an ongoing security incident data.

The Program works by creating a dictionary that will contain details about a cyber security incident. It will then display to the user the username and IP address before adding a new field called status. the risk level of the incident will also be updated from high to critical, The program will remove the event type from the dictionary too.

After the program has ran and made the necessary updates it will display the remaining security incident details including all the keys and values that are stored in the dictionary it will also display the total number of key value pairs remaining in the dictionary too.
