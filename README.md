Description of the Program and how the program works
-

This program is Called Cyber Security Utilities using User-Defined Modules the program works will use a User-Defined module called security_tools. To store repeated Cyber Security functions. The Program will validate passwords and IP addresses entered by the user, The program will also generate and suggest a strong password to use instead of the one the user enters if the password doesn't meet the required rules for a strong password.

The Program is made up by 2 python files security_tools.py and Main.py. The security_tools.py program is the program that contains the user-defined modules and reusable functions where as the Main.py program is the program that gets and loads these modules so that user can interact with the program and use it.

The program works by importing the secuirty_tools.py modules into the Main.py program. The user is then asked to enter a password at least 8 characters or more the password must contain a mixture of letters, numbers and special characters.

if the password entered by the user does not meet the necessary security requirements then the program will generate a stronger password for the user to use instead.

After that the program will ask the user to enter a valid IP address. The IP function that is present in the security_tools.py code will check that the IP that has been entered by the user contains 4 octets, The Ip is separated by 3 dots and that each octet contains a value between 0 and 255.

After all Checks are done the program will display whether the password and IP entered by the user is valid output or invalid output.

The two files that were used to create this Task was Main.py and security_tools.py
