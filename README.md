Task 1 Security Tool
-
the First task I have made is a Basic security tool for a small organisation. to use this tool you first must log in an authenticate before being able to use the tools features the tool has the 4 following functionalities 1. Security event Counter, 2 A brute force Simulation , 3 Login authentication and lastly number 4 the option to exit the tool the four tools do the following.



 1. Security event Counter - The security event counter will record 10 password attempt made by the user the tool will count the correct and incorrect entries made it will then calculate a percentage of the failed password attempts and it will alert the user if entries typed exceed 50%.


 2. Brute force Simulator- The brute force simulator will simulate a password guessing attack by allowing the user to enter a limited number of passwords to be entered until the correct password is entered or the maximum number off attempts are reached.

 3. Login authentication- the Login authentication will verify a username and password the user will have 3 attempts until the correct password is entered or max attempts are reached before freezing the account for 24 hrs

 4. Exit - Exiting will exit and close the program  and display a thank you message
