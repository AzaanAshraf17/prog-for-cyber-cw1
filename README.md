Description of the Program and how the program works
-

The Security Tool program is tool that requires the user to log in to the tool before accessing a menu of 4 Cyber Security Functions such as A security event counter a brute force simulator , the ability to test Login authentication of the tool and finally being able to exit the security tool program.

The Username used in this program is admin the password used in this program is pass123 having a username and password helps keep this Security tool menu secure without any unauthorised access happening.

Menu Options/Functions
-
Option 1- the Security Event Counter 
-
This options will ask the user to enter the password 10 times, the tool will then count the number of correct and incorrect attempts made by the user from this it will calculate a percentage of the failed tries that were made and will display an alert if 50% or more passwords entered are incoorect.

Option 2- Brute force Simulator
-
This option will simulate a brute force attack it will ask the user 5 times to guess the correct password the program then displays whether the passwords was guessed successfully and how many attempts were taken.

Option 3- Login Authentication 
-
This option will ask the user to enter the username and password the user gets a maximum of 3 attempts to enter the correct username and password if the 3 attempts made were incorrect the account is then frozen for 24hrs. 

Option 4- Exit
-
This option will close and exit the program and print a thank you message to the user.
